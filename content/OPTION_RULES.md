# Vocabulary Option Rules

Every multiple-choice item must follow this structure:

1. Correct option: a synonym or the closest same-meaning expression for the word.
2. Wrong option A: an antonym or opposite-meaning expression.
3. Wrong option B: a related word or related description, but not the same meaning.

If a clean synonym is difficult:

1. Correct option: a meaning description that does not reuse the same root as the word.
2. Wrong option A: an opposite-meaning description.
3. Wrong option B: a description of a related object, part, cause, result, field, or nearby concept.

Examples:

```text
Word: lonely
Correct: solitary
Wrong A: sociable
Wrong B: melancholy

Word: airplane
Correct: a machine that flies through the sky
Wrong A: a machine that travels under water
Wrong B: a machine part that helps create movement

Word: car
Correct: automobile
Wrong A: pedestrian
Wrong B: wheel
```

Do not use placeholder or meta-language in student-facing choices:

```text
unrelated
distractor
different concept
scholarly meaning
concrete household object
brief practical task
incorrect meaning
```

All three choices must have the same style. If the correct answer is a term, both wrong options should be terms. If the correct answer is a description, both wrong options should be descriptions.
